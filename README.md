# Gerador de Prompts

Página web simples para montar prompts completos para IA. Preencha os campos (papel, tarefa, contexto, público, formato, tom, regras, exemplos) e copie o prompt pronto com um clique.

## Como usar

Abra o arquivo `index.html` no navegador. Não precisa instalar nada nem rodar servidor.

- O prompt é atualizado em tempo real enquanto você digita.
- Só o campo **Tarefa** é obrigatório; campos vazios ficam fora do prompt.
- Use **Começar de um modelo** para carregar exemplos prontos (marketing, código, estudo, e-mail).
- O que você digitou fica salvo no navegador, então nada se perde ao recarregar.

## Arquivos

- `index.html`: estrutura do formulário
- `style.css`: visual (com tema escuro automático)
- `script.js`: montagem do prompt, modelos e botão de copiar
